# SlackHarder

macOS 原生桌面遮罩，使用 Swift + AppKit，无第三方依赖。需要 macOS 13 或更高版本；从源码构建另需 Swift 6 工具链。

## 下载和安装

从 [GitHub Releases](https://github.com/hibiki-ovo/SlackHarder/releases/latest) 下载 `SlackHarder-版本号-macOS-universal.zip`，支持 Apple Silicon 和 Intel Mac。解压后将 `SlackHarder.app` 拖入「应用程序」。

免费分发版本使用临时签名（ad hoc），未经过 Apple 公证。若系统阻止打开，请确认下载来源后，在「系统设置 → 隐私与安全性」点击「仍要打开」。受管理设备可能不允许此操作。首次运行请在「隐私与安全性 → 辅助功能」中授权 SlackHarder；更新后若权限失效，请移除旧授权并重新添加。

启动后通过菜单栏鱼形图标操作，不显示 Dock 图标。

## 启动

```sh
git clone https://github.com/hibiki-ovo/SlackHarder.git
cd SlackHarder
swift run SlackHarder
```

通过菜单栏的鱼形图标选择「自动模式」或「手动模式」。启动默认进入自动模式并弹出窗口选择器，选择并成功附着后显示遮罩；取消选择时保持隐藏。首次运行需按提示授予辅助功能权限，再重新选择窗口。

## 全局不透明度

两种模式共用「遮罩不透明度」滑块，支持 0%～100% 连续调节并实时生效，自动保存。切换模式不改变不透明度，重启后恢复。

遮罩置于普通应用窗口上方，默认鼠标穿透，可操作下方应用。置顶不保证覆盖系统安全界面或所有独占全屏应用。

## 手动模式

- 默认显示遮罩，可通过菜单「显示遮罩 / 隐藏遮罩」切换。
- 勾选「编辑遮罩（移动 / 缩放）」后，通过标题栏移动、窗口边缘拉伸；结束编辑后恢复鼠标穿透。进入编辑会显示遮罩。
- 位置和大小自动保存，重启或从自动模式切回时恢复；切回手动模式默认显示。屏幕变化导致窗口完全移出可见区域时自动居中。
- 「将遮罩移回当前屏幕」用于恢复窗口位置。
- 手动模式不控制外部应用窗口，鼠标侧键不执行隐藏 / 恢复。

## 自动模式

1. 选择「自动模式」会弹出窗口选择器。未选择附着窗口前，遮罩隐藏，窗口控制不可用。取消选择会保持等待状态。
2. 首次使用选择「授权辅助功能…」，在系统设置「隐私与安全性 → 辅助功能」中允许系统提示的程序。授权后如仍无法读取窗口，请重启程序。
3. 窗口选择器先显示加载状态，在后台查询普通应用的窗口，期间可以取消。按「应用名 · 窗口标题」选择目标，点击「附着」，可点击「刷新列表」更新。慢响应会受请求超时和单应用时间预算限制，列表可能暂时缺少未响应应用的窗口，可稍后刷新。确认后恢复并激活所选窗口，遮罩自动显示、覆盖整个窗口并跟随其移动和缩放。点击已附着窗口菜单项可重新选择目标；取消重新选择时保留原目标。
4. 目标应用隐藏、退出、窗口最小化、关闭，或切换到其他窗口 / 应用时，遮罩自动隐藏；返回目标窗口后自动恢复。
5. 鼠标前进键或后退键固定用于隐藏 / 恢复附着应用：隐藏该应用全部窗口，再按一次恢复应用并将附着窗口置前。一级菜单「鼠标侧键：隐藏」可执行同样操作，隐藏后自动变为「鼠标侧键：恢复」。不再提供最小化选项，也不读取此前保存的侧键行为偏好。不改变遮罩不透明度。
6. 「解除附着」后保持自动模式，隐藏遮罩，等待重新选择目标。切换手动模式会清除附着关系并恢复手动遮罩。

自动模式没有独立的显示 / 隐藏开关，不允许手动拉伸。目标窗口尺寸不会覆盖手动模式保存的尺寸。附着关系仅本次运行有效，重新进入自动模式或重启后需重新选择。

窗口移动、缩放、最小化、恢复和前台切换通过系统通知触发更新，另保留每 0.5 秒一次的兜底查询。侧键操作会先隐藏遮罩再发送控制请求，状态读取和控制请求在后台串行执行；连续通知合并刷新，过期结果不会重新显示遮罩。读取失败或权限被撤回时隐藏遮罩。部分应用不支持通知，可能依赖兜底查询。游戏、自绘窗口、全屏及跨桌面场景需实际验证。

恢复时，如果目标窗口已取消最小化且位于前台，就跳过重复置前。置前请求返回 `AXError.cannotComplete` 时，会在短时间内确认窗口实际状态，避免将动画期间的响应超时误报为恢复失败；无法确认成功或遇到其他错误时仍提示失败。

鼠标侧键读取系统真实状态，兼容手动隐藏或最小化。隐藏请求发送后等待系统确认，避免遮罩短暂重新出现。应用隐藏不等于退出或暂停进程；如果附着窗口本来已被手动最小化，恢复它时仍可能出现系统动画。

隐藏端不会仅因 `hide()` 返回失败就中止，会先等待实际隐藏状态更新；仍未隐藏时通过辅助功能的应用隐藏属性尝试一次备用请求。只有应用确实隐藏才确认成功，切到后台不等于隐藏；备用接口明确报错或始终未隐藏时仍保留错误提示。

恢复应用时同时尝试取消隐藏和激活，以实际的未隐藏、已激活状态确认结果，不会仅因 `unhide()` 请求返回失败就中止。若直接请求未生效，会使用系统打开应用接口恢复同一安装位置的运行实例，并验证 PID。多个实例或进程已变化时停止备用恢复，要求重新选择目标。

侧键监听不阻止其他应用收到全局侧键，浏览器仍可能执行前进 / 后退。鼠标驱动如将侧键映射为键盘快捷键，需要改回标准鼠标侧键。

实现通过 Apple 的 [Accessibility API](https://developer.apple.com/documentation/applicationservices/1462085-axuielementcopyattributevalue) 读取窗口属性，并设置最小化状态。操作失败时提示原因，日志记录目标 PID、窗口标题、操作及 AXError。

偏好设置保存在 `local.desktop-mask` 的 UserDefaults 域中，不依赖启动目录。

## 构建和测试

```sh
swift build
swift test
```

可用 Xcode 打开 `Package.swift`。自动化测试覆盖模式切换、显示规则、窗口控制启用条件、多屏坐标转换，以及请求的后台执行、错误恢复和取消；辅助功能授权、鼠标和窗口交互需本机验证。日志记录窗口列表和窗口控制的耗时，方便实机对比。

## 打包和发布

```sh
bash scripts/package.sh 0.1.0
```

生成 `dist/SlackHarder-0.1.0-macOS-universal.zip` 和 SHA-256 校验文件，包含双架构 `.app`。打包脚本使用本地临时签名，不需要开发者会员。

向 GitHub 推送 `v0.1.0` 格式的版本标签后，GitHub Actions 会运行测试、打包并发布 Release。后续版本使用新的版本号和标签。

已安装 GitHub CLI 并通过 `gh auth login` 登录具备仓库写入权限的账号后，也可以运行：

```sh
bash scripts/publish.sh 0.1.0
```

脚本在临时目录克隆远程仓库，复制当前源码、提交并推送版本标签；保留远程历史，不执行强制推送。工作流需要仓库允许 GitHub Actions 运行。
